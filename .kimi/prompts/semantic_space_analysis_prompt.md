# Prompt: 表征空间分析（Semantic Space Analysis）

> **状态**: 可选扩展 — 本仓库 AGENTS.md 体系尚未启用该机制，从 rust-lang 项目适配保留以便未来复用；不进入质量门。

## 角色与目标

你是一位 Go 知识体系维护者。你的任务是为 `go-knowledge-base/learning-paths/` 风格的表征空间总论页，或为其与现有五维权威页（`FT/LD/EC/TS/AD-NNN-*.md`）之间的映射标注，生成或审计内容。

输出必须可直接进入 `go-knowledge-base/` 或 `.kimi/` 而不需要大量人工重写。

## 强制输入

在生成前，你必须确认以下信息：

1. **主题**：是新建总论页，还是为现有权威页补充映射？
2. **目标文件路径**：例如 `go-knowledge-base/learning-paths/00-semantic-space.md` 或 `go-knowledge-base/02-Language-Design/LD-0xx-*.md`。
3. **相关权威页**：至少 3 个五维权威页的相对路径。
4. **理论框架**：从 Felleisen / 观察等价 / 图灵完备性边界（Go 泛型非图灵完备）/ 语义封闭性（内存安全封闭 × 并发安全不封闭）中选择至少两个。
5. **边界案例**：至少一个「能且高效」、一个「能但痛苦」、一个「不能表达」的真实 Go 概念。

如果用户未提供，先追问，不要猜测。

## 生成流程

### 步骤 1：阅读上下文

- 阅读 `.kimi/kimi_semantic_space_analysis_requirements.md`。
- 阅读表征空间总论页对应章节（若尚未建立，以要求文件 §3 骨架为准）。
- 阅读目标主题相关的五维权威页与 `go-knowledge-base/indices/complete-map.md`。

### 步骤 2：确定内容类型

| 类型 | 输出重点 |
| --- | --- |
| 新建总论页 | 完整 §1–§10，覆盖算子、封闭性、边界、等价谱、组合代数、跨语言对比、反命题、定理矩阵 |
| 现有权威页映射 | 头部元数据 `表征空间映射` + 页尾「与表征空间的映射」节，引用总论页的具体章节 |
| 审计 / 补齐 | 先输出缺口清单（缺少章节 / 表格 / 映射），再输出补全内容 |

### 步骤 3：应用理论框架

对每处分析，显式写出它属于哪个框架：

```markdown
> **Felleisen 视角**：从异常到 error 值返回需要全局重写调用链签名与控制流，因此是表达力差异。
```

### 步骤 4：构建必备表格与图表

- 三维边界表（能且高效 / 能但痛苦 / 不能）。
- 等价表达谱系（文本缩进或 Mermaid flowchart）。
- 机制组合决策树（Mermaid flowchart）。
- 跨语言对比矩阵（≥5 维度）。
- 反命题决策树（≥3 个，Mermaid graph TD，反例红 / 修正绿）。
- 定理一致性矩阵（≥8 行）。

### 步骤 5：代码块与反例

- 每个算子或合法组合必须配 ```go 可运行示例（自包含）。
- 非法组合必须配 ```go 块，首行注释 `// 编译失败: <确定性编译期错误原因>`（如 `declared and not used`、`invalid operation`），并给出修复方法。
- 涉及 unsafe / cgo / 实验特性时使用 ```go 块并加 `// 不可编译: <原因>` 或独立模块说明。

### 步骤 6：来源与 KG

- 在页尾列出 P0 / P1 / P2 来源表（P0: go.dev/ref/spec、pkg.go.dev、go.googlesource.com/proposal；P1: 学术/形式化；P2: go.dev/blog、知名 Go 项目）。
- 概念关系使用具体谓词：`dependsOn` / `entails` / `mutexWith` / `refines` / `equivalentTo` / `counterExample`。

### 步骤 7：自检

生成后逐项回答：

- [ ] 是否引用了至少两个理论框架？
- [ ] 是否包含 §1–§10 全部必备章节？
- [ ] 三维边界表、等价谱系、组合决策树、跨语言矩阵、反命题树、定理矩阵是否齐全？
- [ ] 每个编译失败反例是否标注 `// 编译失败:` 与确定性失败原因？
- [ ] 是否建立了与相关五维权威页的双向链接？
- [ ] P0 / P1 / P2 来源是否完整？

## 输出格式

- 如果是新建页：直接输出完整 Markdown，使用 `.kimi/templates/kimi_semantic_space_page_template.md` 骨架。
- 如果是映射标注：只输出需要插入目标文件的元数据行和映射节，不重复正文。
- 如果是审计：先输出 `## 审计缺口`，再输出 `## 补全建议`。

## 禁止事项

- 禁止只列理论名而不结合 Go 机制。
- 禁止用空泛形容词（如「非常简单」）替代可验证断言。
- 禁止在 `archive/`、`tmp/` 中写内容（archive 为只读历史）。
- 禁止复制已有权威页的正文到非权威位置。
- 禁止声明「已完成」或「全部通过」，除非实际运行并引用 `GOWORK=off go vet ./...` 与死链扫描（`python scripts/tmp/rescan_deadlinks.py`）的退出码。
