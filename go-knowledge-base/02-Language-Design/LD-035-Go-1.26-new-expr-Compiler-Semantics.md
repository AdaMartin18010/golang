# Go 1.26 new(expr) 编译器语义与 SSA Lowering

> **文档编号**: LD-035
> **分类**: 02-Language-Design / Language Features
> **Go 版本**: 1.26+
> **最后更新**: 2026-05-06

---

## 一、语言规范变更

Go 1.26 对内置 `new` 函数进行了语义扩展：

```go
// Go 1.25 及之前：操作数必须是类型
new(T) // *T

// Go 1.26：操作数可以是表达式
new(expr) // *typeof(expr)，初始值为 expr 的求值结果
```

**规范原文**（go.dev/doc/go1.26）：
> The built-in `new` function, which creates a new variable, now allows its operand to be an expression, specifying the initial value of the variable.

---

## 二、类型推导规则

```text
new(expr) 的类型推导:
────────────────────────────────────────
1. 求值 expr，得到值 v 和类型 T
2. 在堆（或栈，见逃逸分析）上分配 sizeof(T) 的内存
3. 将 v 写入该内存
4. 返回 *T

特殊情况:
├─ new(42) → *int，值为 42
├─ new(yearsSince(born)) → *int，值为函数返回值
├─ new(Config{Host: "localhost"}) → *Config，值为复合字面量
└─ new("hello") → *string，值为 "hello"
```

## 三、SSA Lowering

### 3.1 编译器前端处理

```go
// 源代码
age := new(yearsSince(born))

// AST 表示
CallExpr {
    Fun: Ident("new")
    Args: [CallExpr{Fun: Ident("yearsSince"), Args: [Ident("born")]}]
}

// 类型检查阶段
// new 的实参类型为 int（yearsSince 的返回类型）
// new 的整体类型为 *int
```

### 3.2 SSA 生成

```text
// Go 1.26 之前：new(T) 的 SSA
v1 = Call <*int> runtime.newobject(int)
v2 = Store v1 42

// Go 1.26：new(expr) 的 SSA
v1 = Call <int> yearsSince(born)     // 先求值表达式
v2 = Call <*int> runtime.newobject(int)
v3 = Store v2 v1                     // 用表达式结果初始化
```

### 3.3 逃逸分析优化

```go
// 如果 new 的结果不逃逸到堆外，编译器可在栈上分配
func localNew() *int {
    return new(42) // 如果 42 不逃逸，可能在栈上分配
}
```

## 四、与 &T{...} 的等价性分析

```go
// 对于复合字面量，new(T{...}) 与 &T{...} 在结果上等价
cfg1 := new(Config{Host: "localhost"})
cfg2 := &Config{Host: "localhost"}

// 区别:
// 1. new 的语义是"创建新变量并初始化"
// 2. & 的语义是"取复合字面量的地址"
// 3. new 可以接受任意表达式，& 只能用于复合字面量
```

## 五、典型应用场景

### 5.1 序列化中的可选字段

```go
func personJSON(name string, born time.Time) ([]byte, error) {
    return json.Marshal(Person{
        Name: name,
        Age:  new(yearsSince(born)), // 无需临时变量
    })
}
```

### 5.2 指针字面量简化

```go
// 之前
enabled := new(bool)
*enabled = true

// Go 1.26
enabled := new(true)
```
